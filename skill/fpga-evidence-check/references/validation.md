# 已验证效果与复用方式

## 输入及预期

- 计数器夹具：复位及3个计数结果0/1/2/3；实际CSV换行顺序但ID保持，应通过。
- FIR夹具：输入1/2/3/4，4个全1系数，零初始历史；输出1/3/6/10。`fir_actual.csv`应通过；注入`y3=11`的`fir_bad.csv`应被拒绝。
- 两组数据均为显式合成夹具，不是从FPGA运行导出的仿真/实测结果。它们证明CSV检查可用于不同题目，不证明计数器或滤波器硬件已跑通。
- 新目录试验只复制一个脚本和两份计数器CSV，以`python -I -B`从新工作目录执行，不导入原项目模块，不依赖Qt/Vivado/协议包。

## 行为验证

运行`python -B skill/fpga-evidence-check/scripts/test_evidence_check.py`。覆盖哈希一致、同长度篡改、缺失、不覆盖旧清单、非法路径、重复JSON/ID、缺列、空数据、非法数值、容差闭边界、长十进制精度及新目录部署。符号链接项若操作系统不能创建则显式skip，不把skip伪称通过；最终实际计数见随包`validation_result.json`。

`validation_result.json`区分脚本测试数、预期拒绝案例、实际工程清单比对和新增硬件事务数。期望失败的CSV退出1是测试通过条件，不应删除这个负例。

## 迁移到新题目

1. 固定新题目的输入、单位、事件端点、黄金参考与容差依据。
2. 从新题目的验证程序导出`id,value`；转换器应有自己的正反例，不在本工具资格中自动继承。
3. 选定要交付的源码、固件与配置，显式seal；清单和需求矩阵分别保存。
4. 另一目录收到文件后check，并compare参考与实际结果；保留JSON输出和退出码。
5. 综合/实现/上板仍按新题目实测完成，不能从本目录示例直接继承。

已验证为当前Windows/Python环境的离线行为与新目录复用；Linux/macOS及其他实板迁移属于适用设计范围，未冒称实测。十进制数字最多4096位且指数绝对值不超过4096；超出拒绝，不尝试无限精度运算。
