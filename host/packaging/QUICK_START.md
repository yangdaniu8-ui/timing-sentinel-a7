# Timing Sentinel A7 · 一键负载实验版 0.4.7

## 0.4.7 新增：六任务实验与自动保存

使用已烧录的STM32 FIR／IRQ任务固件与USR38 FPGA固件，沿用原七根线。连接实际CH340串口后，选择“3.5 ms · 观察超期”或“8 ms · 宽窗对照”，点击“六任务实验＋自动保存”。若电脑已有尚未保存的实物波形，先保存。板端若仍FROZEN，程序会完整读取、重复核对并保护旧记录，然后开始六个连续任务，三档各两次。每份新波形在核验及保存成功后才释放；末轮留在板端。三档GPIO均值直接显示，点击“打开实验报告”查看详细结果和记录路径。

“载入任务预设”只改电脑上的配置草稿，适合手动提交／单次采集；不会自动ARM或清除波形。“六任务实验＋自动保存”会自行提交所选预设，不需要再手工填写规则。3.5ms是演示门限；重负载出现TIMEOUT与证据核验通过可以同时成立。8ms用于同一任务的宽窗对照，实际结论以波形为准。

保存目录中包含protected_previous.tscap（若有旧冻结记录）、六份round_*.tscap、experiment.json和summary.html。停止、通信错误、部分传输或保存失败均中止后续流程，保留已有文件和当前板端状态；未得到完整保护的旧记录不会释放。批量统计按负载分组，每组两份仅作演示。GUI检查E2身份、样点、事件和时间规则，不读取MCU内部FIR／ISR校验。

此流程不烧录两板、不需要安装Python／Vivado／ST-Link软件。现有STM32固件按编号自动轮换负载，不能在GUI里任意指定下一档。任务编号上限4095，接近上限时保留当前记录并提示；需要完整重新上电后从1开始。当前真实任务固件期间请使用这个六任务按钮；旧“自动六轮SPI验收”需要旧六场景MCU镜像。运行、启动或连接本身不自动执行实验。

## 0.4.6 新增：真实任务负载身份自动显示

打开或读取STM32任务实验的记录，波形上方自动显示“无中断 / 轻度中断竞争 / 重度中断竞争”、任务编号、标称中断频率及相位标记。依据记录内E2十字节标记及校验字节识别，不依赖文件名、轮号顺序、MCU诊断注释或PASS/TIMEOUT。完整实物记录还核对UART样点和全部标记事件、GPIO/SPI及规则；部分数据、模拟、标记损坏或证据不一致明确提示未验证/未通过。核验一致不等于任务正确或规则PASS，标称频率不是实测频率。

不接板即可点击“打开GPIO/SPI记录”，选择本包workload_records：validation_…raw_0001/0002/0003分别是无中断、轻度、重度；pilot_…raw_0003是宽窗口下重度但PASS的对照。身份随当前波形显示，板端后续状态不改旧记录的身份。完整解压后运行EXE，不需要新接线或重烧两板。

**当前STM32已换任务实验固件，不是D0–D5六场景固件。不要点击“自动六轮SPI验收”或用KEY0默认配置代替任务实验配置。**任务实验需要R0/R2启用、R1/R3禁用、5MS/s、pre45000/post20535、演示窗口0–3.5ms，A=A5、R0=CH1上升沿、R2=SPI C3，动作均“每事务触发”。识别模块只读记录，不自动改配置、ARM、释放或烧录。旧六场景记录仍可回放。

批量统计仍按完整配置分组，不按新负载身份重新分组。研究单档抖动请只选同一负载的记录；三档混算不等于单档抖动。附加workload_experiment中的MCU诊断不在本版身份核验范围内；没有注释的raw同样可以识别。

## 0.4.5 新增：批量统计与报告

点击右上角“批量统计 / 报告”，按住Ctrl多选已保存的tscap，也可先进入下方同名页签后点“选择多份tscap并分析”。完成后按配置组显示四规则结果数量、匹配延迟均值、实际观测响应的均值/总体标准差/P95/P99。导出HTML报告可直接用浏览器打开，带分布图及逐文件核验原因；JSON保留完整配置和SHA256便于追溯。无需连接开发板，不发送配置、ARM或释放，也不会把导出报告当作保存了未保存的原始记录。

重复读取同一次冻结记录即使电脑UUID不同也只计一次，原始文件不改。完整实物、单事务、无手动停止/日志覆盖/截断且波形重判一致才纳入延迟统计。重判直接解析UART、GPIO、SPI样点，不依赖D0–D5演示标签。损坏、部分、模拟、多事务、边界量化不明确等记录保留状态与原因，不强行判为合格。最多选择2500份，每份输入限2MB。

“匹配延迟”不包含超时；“观测B延迟”可以包含超时后真正出现的匹配响应，无响应显示—而不是0。按来源/固件/完整采样规则配置分组，不把不同窗口混算。默认演示有故意对照规则，所以TIMEOUT计数不是系统故障率。同配置的不同场景可能混在一组，混合标准差不是单场景抖动；研究抖动请只选同一工作条件的重复记录。异常-only保存的数据不代表全部事务的延迟分布。

同目录的experiment.json只读作为上下文，原FAIL或通信重试不会因为波形重判成功而被改成PASS；累计通信快照不能相加当作本批错误数。报告只描述所选记录，使用标称时钟，不是正式对照验收。HTML/JSON输出不能覆盖原始tscap或任何experiment.json。统计失败/取消保留此前的报告，不改板端状态。

命令行也可完全离线处理：`TimingSentinelA7-SPI.exe --analyze-directory "D:/my_records" --analysis-report "D:/my_reports/analysis_report.html"`，只扫描该目录第一层tscap；或用`--analyze-records`逐一指定文件。不能与--port或硬件长测参数混用。退出成功仅表示分析流程完成，不表示所有记录或整机通过验收。

0.4.5不改变0.4.4的波形参考点、单位、场景和CSV/VCD语义，不需烧录两板。原0.4.4/组合b03/b04保留。

## 0.4.4 界面变化

“当前波形场景”根据本次记录内唯一D0–D5→A5演示标记自动显示中文名称，另列样点/事件/规则的一致性核验。无标记、多事务、部分数据或核验不符会提示未识别/未验证/未通过，不根据轮号或文件名猜测，不把模拟数据算作实物验收。旧波形仍标明自己的session/config，不冒充新板端记录。

波形默认以唯一A事件（合法UART字节，通常为A5）为零点，GPIO响应的横坐标与“A→B/观察到B ms”一致。无唯一A则明确回退主判定或首样点。可切换主判定/首样点参考，以及ms/μs显示；切换单位不会修改原始tick或数据。事件表相对时间始终是ms，并随波形的参考点切换。CSV/VCD保持0.4.3原有参考语义（CSV相对判定/首样点，VCD从首样点0起算），不随显示零点改变。

默认收起规则配置，为波形和事件让出空间；展开后配置区可滚动。拖动波形与下方事件之间的分隔条可改变两区高度。默认“仅关键事件”显示场景字节、触发、GPIO/片选边沿、SPI完成/错误及规则结果，原始事件全部保留；取消勾选可查看所有事件。单击事件行把游标定位到同一时间，若事件在已收到样点之外则只提示，不生成波形。

“A→响应”显示触发到响应/截止窗口；“放大SPI”聚焦实际CS低电平段并改为μs，方便数时钟。默认只显示配置用到的通道，取消“仅已配置通道”可看全部八路。GPIO合格窗口、迟到响应和SPI字节直接标注在图中。四规则并非全部PASS才算正常，R1/R3是对照，默认正常矩阵PASS/TIMEOUT/PASS/TIMEOUT。

本版只改上位机，现有接线及两板固件不变，不需重新烧录。六种历史实物记录离线回放和界面/导出检查不等于0.4.4已经重新完成现场采集、600轮长测或另一台电脑验收。

本包是 Windows x64 免安装版，不需要安装 Python、VS Code 或 Vivado。解压整个文件夹，双击 TimingSentinelA7-SPI.exe；不要只复制 EXE，必须保留 _internal 文件夹。未签名，可能出现系统安全提示；仅使用可核对哈希的可信副本。未在另一台干净机器上验收。

## 不接板先看效果

点击“打开GPIO/SPI记录”，打开 demo_records 中的 normal/early/late/missing/wrong_byte/truncated.tscap。这些是已经保存的实物采集，不是当前在线采集；回放不会ARM或释放板端记录。R0/R1是GPIO窗口，R2匹配SPI C3，R3匹配SPI 3C。“TIMEOUT”可能是预期结果，请比较整个四规则矩阵。

## 接真实板

FPGA必须运行 mvp5-a7-0.1.0/profile5 兼容固件。当前项目按键版已于2026-10-11整片Flash清空重写并完成用户确认的完整断电/KEY0启动与真实波形验收。本次0.4.4只改上位机，不需要再次下载；不能从相同的协议INFO字符串推断其他板子也已安装按键固件。板载USB_UART与JTAG是两条独立连接。选择实际CH340串口，不硬编码COM号码，点“连接/确认SPI固件”。启动/连接不会自动ARM；固件不匹配时拒绝采集，不切模拟数据。

## 板载按键演示（仅适用于通过实物验收的按键固件）

KEY0短按：仅IDLE开始一轮默认四规则GPIO/SPI测试。KEY1长按约2秒：明确丢弃本轮冻结数据，仅允许释放按键启动的记录；未保存的数据会消失，重要数据请先读取并保存。释放不自动开始下一轮，需要再按KEY0。KEY3消音；不清除判定或证据。RESET不是释放键，会复位采集并丢失RAM记录，请不要混用。

“监听板载按键”默认开启，每500ms只读观察状态并在配置变化时回读配置；也可关闭后点击“更新板端状态”。不会配置、ARM或释放。新轮冻结后点“读取冻结波形”并保存；旧波形不会被状态更新静默清空，界面会提示它不是当前新记录。通信繁忙时按键启动可能被忽略，松开稍后再按即可。上位机生成旧记录回放不证明按键实物已验收。

现有接线按板上印字：STM32 A9/PA9→FPGA R17/J2-3(CH0 UART)，B0/PB0→N15/J2-5(CH1 GPIO)，A8/PA8←P20/J2-8(READY)，G/GND→J2的GND；A5/PA5→R16/J3-35(CH2 SCK)，A7/PA7→P15/J3-36(CH3 MOSI)，A4/PA4→R14/J3-37(CH4 CS)。两板各自供电，只连3.3V信号及地，不并接电源，不接5V信号。J2-54/56不是地。按键默认场景使用现有STM32 SPI mode0/250kHz固件，不需新外设或信号线。其它模式的基础版补测不代表此新变体已重新验收。

## 新增CSV/VCD波形导出

读取波形或打开历史tscap后，点击“导出 ▾”，选择“JSON元数据”、“CSV逐点波形”或“VCD数字波形”。这只处理电脑已有记录，不发ARM/释放，不把“已导出”等同于“已保存原始记录”。重要证据仍先用“保存记录”另存tscap。

CSV为UTF-8带BOM，一行一个实际收到的样点，含身份、来源、传输完整性、取消/截断/日志覆盖标志、CH0–7、48位tick、从首点起的elapsed_ns以及相对判定时间的relative_to_decision_ns。reference_kind为first_sample时相对的是首点而不是不存在的判定。时间为按记录内时基换算的整数标称纳秒。

VCD为标准数字波形格式，timescale为1ns，时间从首样点0开始，实际点距是20ns×sample_divisor；仅保留实际采样电平变化和最后收到样点的时间，不把规则20ns事件伪装成100ns样点之间已测到的跳变。文件comment中保存身份、来源、参考点、规则结果及完整性。可在支持VCD的波形查看工具中打开CH0–7。

部分读取只导出收到的前缀，不填充缺失样点；transfer_complete=false会保留。波形到齐但事件没到齐也为false；true仅表示传输完整，不表示所有规则PASS或没有手动取消。没有样点时拒绝CSV/VCD，但仍可导出JSON。输出扩展名必须是对应json/csv/vcd，不允许覆盖tscap；失败保留原有输出文件，导出在工作线程执行。

若FROZEN，先“读取冻结波形”→“保存记录”→确认后“释放已保存记录”。IDLE时点“自动六轮SPI验收＋保存”：每轮同一个UART A5事件启动四条并行规则，六轮完整波形/事件/报告自动保存，最后一轮仍冻结。默认保存目录：%LOCALAPPDATA%/TimingSentinelA7/profile5/captures，不写入程序目录。

六场景顺序由STM32当前相位决定，依靠D0–D5标记识别，不凭轮号猜测。正常矩阵 PASS/TIMEOUT/PASS/TIMEOUT；提前 EARLY/PASS/PASS/TIMEOUT；迟到 TIMEOUT/TIMEOUT/PASS/TIMEOUT；缺失全TIMEOUT；错误字节 PASS/TIMEOUT/TIMEOUT/PASS；截断 PASS/TIMEOUT/TIMEOUT/TIMEOUT并有SPI_ERROR。

通信中断时不自动释放、不自动ARM；可保存收到的前缀，重连后读取冻结数据。请勿同时开两个程序占用同一COM。20ns/tick是标称50MHz量化间隔，不是已认证绝对测量精度。

## 复现与诊断

host_source.zip为可编辑源码，requirements-lock/build为开发与打包依赖。普通用户不需要安装这些包。EXE也支持 --open 完整记录路径、--root 保存目录路径。研发CLI的 --soak-count 必须配合 --port、--out 和必要时 --prior-record，明确启动真实实验；普通双击不会执行它。

本包为免安装程序，不包含安装向导或代码签名；版本与验证范围以对应交付说明为准。
