# 测试条件与结果

## 实物实验

| 项目 | 条件与已取得结果 |
| --- | --- |
| 另机双期限实验 | 3.5/8 ms各六任务，三档各两次，共786432样点、24条启用规则；保存、重连、回放通过 |
| 同事务四规则 | 六任务，393216样点、24条规则；共享同一A，每对共享同一实际B；重载TIMEOUT/PASS/TIMEOUT/PASS，其余全部PASS |
| 受控重复任务 | 同一USR43镜像600任务，六种组合各100次，约89.99分钟，39321600样点、1200条启用规则重判 |
| ILA内部观察 | 临时调试镜像12任务，12288行tick限定数据与波形/事件对照；正式Flash不含ILA |
| Flash启动 | 已做整片擦写读回、实际断电后按键声光及记录读取；冻结BRAM记录须先保存 |

上述实验都按各自版本和原始记录计数，不将一次重复读取当作新任务，也不把历史回放当作实测采集。通信完整性通过记录身份、长度、CRC及样点重判核对。

## 软件及文字整理

上位机离线回归435项。交付源码路径迁移与免安装EXE分别做过测试，新EXE支持读取、保存、取消保护、断开重连及历史四规则回放。本仓库的界面/说明文字调整另做回归，不改变判定、采集、协议或固件。

原预设提供声光，同事务四规则模式明确仅波形。记录来源、当前连接、板端状态和本地保存状态分开显示。统计按完整配置分组、去重，不把TIMEOUT后的实际响应或缺失响应都写成0。

## 正式FPGA实现

LUT7609/20800（36.58%），FF7833/41600（18.83%），BRAM36Kb等效22/50，DSP0；50 MHz约束下WNS3.346 ns、WHS0.055 ns，原资格默认DRC0项违规。资源与时序针对正式USR43，不混用临时ILA镜像。

## 使用条件

本文实物输入为UART115200、SPI mode0/250 kHz、5 MS/s波形采样和3.3 V逻辑；时间按50 MHz标称时基换算。CH5至CH7接入及其他速率应分别验证。READY受控实验和上传空档不等于自由运行的连续无盲区监测，小样本均值也不构成全流尾延迟保证。
